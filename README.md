A haiku about debugging, in the 5-7-5 syllable shape:

> Blame points at my name
> three winters back, I wrote it
> past me sends regards

`main.py` keeps the poem as data, looks every word up in a syllable table at run time, and writes the entry to `/output/entry.txt` only after the 5-7-5 shape and the 1-200 character gate both check out.
